- FIN-368: строгая актуальность ответов по точным версиям всех использованных финансовых источников, включая stale-снимки аналитики и список периодов; приватные baseline сохраняются nullable JSONB без backfill старой истории. Технические векторы исключены из JSON модели и публичного API. Строгий JSON не превращает null в известный ноль; временный bare transport отказ сервиса версий показывает сохранённую историю с `unverified`, сохраняя ошибки авторизации и текущего формата; source потока повторно сравнивается с primary.

- FIN-225: подключён опубликованный go-idempotency v0.6.0 с сохранением typed Status/Any и пересчётом ожидания replay от абсолютного срока без продления ключа. Отсутствие/false не повышается, положительное advice ограничено expires_at; фазовые решения до Charge, неизвестные COMMIT и независимый result.retryable новой генерации не меняются. - FIN-225: contracts gen/go обновлён до v0.5.0. Ошибки результата одновременно содержат canonical `google.rpc.Status` и прежние поля потока/истории; сохранённый `retryable`, включая false и старые NULL-записи, сохраняет независимую семантику новой генерации.
